Only claim a specific activity as completed if it was actually performed. Update this section if team members contributed.

## AI-assisted work

AI assistance was used to help:
- Organize the repository and propose a professional file structure.
- Draft the README and supporting engineering documentation.
- Explain the HC-SR04 measurement and servo scanning algorithm.
- Draft/refine the Arduino sketch, including the distance-dependent buzzer states and servo pause/release logic.
- Draft the HTML/CSS/JavaScript dashboard using the Web Serial API and Canvas.
- Prepare wiring tables, setup instructions, and a testing checklist.

## Verification responsibility

AI-generated code and documentation are starting points, not evidence of successful physical validation. The student must compile and upload the sketch, verify the wiring, test the sensor and servo, confirm buzzer behaviour with the actual buzzer type, check browser serial permissions, and record real observations.
